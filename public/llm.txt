# ul0.site

> ul0 is a free URL shortener and branded link management platform. It helps startups, creators, and digital marketers create custom domain short links with click analytics, QR codes, UTM campaign tracking, and more.

## About

ul0.site is a free, no-signup URL shortener that lets anyone shorten links instantly. Beyond URL shortening, ul0 offers a complete suite of productivity tools including QR code generation, WiFi QR sharing, UTM campaign link building, expense splitting with UPI QR codes, JSON formatting, PDF document scanning, and more.

Founded in 2024, ul0's mission is to make branded link management accessible to everyone — from solo creators to growing startups. Premium plans start at just $2/month for custom domain connections, making it the most affordable branded link shortener in the market.

## Core Products & Features

- **URL Shortener**: Free, unlimited link shortening with permanent redirects. No signup required.
- **Custom Domain Links**: Connect your own domain (e.g., link.yourbrand.com) to create branded short URLs. Starting at $2/month.
- **QR Code Generator**: Create free, customizable QR codes for any link with logo upload and color customization.
- **Click Analytics**: Track clicks by device, referrer, country, and daily trends for all links.
- **UTM Campaign Builder**: Generate tracking-tagged links for Google Analytics and marketing campaigns.
- **Developer API**: REST API for programmatic link shortening with authentication and rate limiting.
- **Expense Splitter**: Split group bills and generate UPI QR payment codes.
- **PDF Page Splitter**: Free client-side tool to extract, split, and download individual pages from any PDF document.
- **PDF Scanner**: Browser-based document scanning with filters, cropping, and multi-page PDF export.
- **WiFi QR Generator**: Share WiFi credentials via scannable QR codes.
- **Free Backlink Exchange**: Aesthetic Notion verification badge exchange with dofollow backlinks for indie builders.

## Pricing

- **Free Plan**: Unlimited short links on ul0.site, 1 custom domain, 1 domain link, basic analytics
- **Pro Plan ($3/month or $2/month annual)**: 3 custom domains, 100 domain links, full analytics, API access
- **Business Plan ($9/month or $6/month annual)**: 10 custom domains, unlimited domain links, full analytics, API access, dedicated support
